# Student Performance Data Science Project

## Overview
This is a beginner-friendly data science project created using Python and pandas.
The goal is to analyze student performance based on study hours and attendance.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
The dataset contains:
- Study hours
- Attendance percentage
- Marks scored

## Steps Performed
- Created a CSV dataset
- Loaded data using pandas
- Performed basic data analysis
- Visualized relationships between variables

## Conclusion
Students who spend more study hours and have better attendance tend to score higher marks.
